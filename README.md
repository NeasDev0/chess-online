# Шахматы для игры онлайн

Многопользовательская игра в шахматы с клиент-серверной архитектурой.

## Технологии
- Python
- WebSockets
- Логика игры на сервере

## Структура проекта
- `/client` — клиентская часть игры
- `/server` — серверная часть с игровой логикой

## Как запустить локально
1. Установи зависимости: `pip install -r requirements.txt`
2. Запусти сервер: `python run_server.py`
3. В другом окне запусти клиент: `python run_client.py`

## Как поиграть с другом

### Способ 1 (бесплатно): Локальная сеть или VPN
Этот способ подходит, если вы находитесь в одной локальной сети или используете программу для создания виртуальной сети (например, [Radmin VPN](https://www.radmin-vpn.com/ru/) или [ZeroTier](https://www.zerotier.com/)).

1. Все игроки подключаются к одной виртуальной сети.
2. Хост запускает сервер, в коде (`run_server.py`) указав `host="0.0.0.0"`.
3. Хост сообщает друзьям свой IP-адрес в этой сети (например, в Radmin он выглядит как `1.0.0.1`).
4. Друзья вставляют этот IP-адрес в файл `server_address.txt` и запускают клиент.

### Способ 2 (надежно): Аренда VPS-сервера
Это лучший способ для стабильной игры в любое время, без зависимости от твоего компьютера и интернета.

1. Арендуй самый дешевый облачный сервер (VPS) у любого хостера (например, VK Cloud, Yandex Cloud, TimeWeb, Beeline Cloud). Для шахмат хватит минимальной конфигурации.
2. Установи на него Python и скопируй папку `server` из проекта.
3. Запусти сервер на VPS, указав в коде `host="0.0.0.0"` и открыв порт в настройках фаервола сервера.
4. Теперь сервер доступен по публичному IP-адресу VPS. Все игроки вставляют этот адрес в свой `server_address.txt` и играют.

### Способ 3 (для разработчиков): Проброс портов на роутере
Если у тебя белый IP-адрес (можно узнать у провайдера), ты можешь настроить проброс портов в настройках своего роутера и отдать друзьям свой внешний IP.

## Если возникли трудности
- Убедись, что сервер запущен с `host="0.0.0.0"`.
- Проверь, что порт (по умолчанию 8000) не блокируется файрволом Windows.
- Для VPS убедись, что порт открыт в настройках группы безопасности облачного провайдера.
